# Bối cảnh Workspace
1. Hãy quét thư mục hiện tại để tự động nhận diện danh sách các project/module có mặt (dựa vào `pom.xml`, `mvnw`, `build.gradle`, `build.gradle.kts`, `gradlew`), hoặc cho phép cấu hình qua file `build-projects.json` / tham số dòng lệnh.
2. Tự động chọn lệnh thực thi tương thích hệ điều hành:
   - Windows: ưu tiên `gradlew.bat` / `mvnw.cmd`, fallback về `gradle` / `mvn.cmd`.
   - Linux / macOS: ưu tiên `./gradlew` / `./mvnw`, fallback về `gradle` / `mvn`.
   - Truyền cờ tắt giao diện động của tiến trình con (như `--console=plain` cho Gradle, `-B` batch mode cho Maven) để đầu ra theo từng dòng sạch sẽ, không xung đột mã điều khiển con trỏ với dashboard cha.

# Yêu cầu kỹ thuật bắt buộc
1. **Cơ chế hiển thị Queue tại chỗ (In-place TUI):**
   - Mỗi project có một khung hiển thị cố định `N` dòng log mới nhất (mặc định `--lines 6`, cho phép tùy chỉnh, ví dụ 10 dòng). Khi dòng thứ `N+1` xuất hiện, dòng cũ nhất bị đẩy ra khỏi đỉnh queue.
   - Dùng mã điều khiển ANSI (`\033[{total_lines}A`, `\033[?7l`, `\033[K`, `\033[?25l`) hoặc thư viện chuẩn sẵn có để vẽ lại khung hình mượt mà (~10–12 FPS), không dùng `clear` toàn màn hình gây nhấp nháy.
   - **Chống vỡ khung khi cửa sổ Terminal thấp:** Tổng số dòng vẽ ra (`total_lines`) BẮT BUỘC phải nhỏ hơn chiều cao thực tế của cửa sổ terminal (`shutil.get_terminal_size().lines - 1`), vì mã `\033[NA` không thể kéo con trỏ vượt quá mép trên của viewport hiện tại. Nếu có nhiều project mà cửa sổ terminal hẹp, hãy tự động giảm số dòng queue hiển thị mỗi project hoặc thu gọn các project đang `QUEUED` / đã `SUCCESS` thành 1 dòng tiêu đề.
2. **Quản lý tiến trình song song & Tài nguyên:**
   - Hỗ trợ giới hạn số lượng build chạy đồng thời (`--jobs` / `-j`, mặc định là `4`) thông qua Semaphore để tránh tràn RAM/CPU khi build nhiều project Java cùng lúc. Các project chờ đến lượt hiển thị trạng thái `QUEUED`.
   - Tăng giới hạn bộ đệm đọc dòng (`limit=1024 * 1024` trong `asyncio.create_subprocess_shell`) để không bị văng lỗi `LimitOverrunError` khi Maven/Gradle in dòng classpath quá dài.
   - Lọc bỏ toàn bộ mã ANSI điều khiển con trỏ và ký tự `\r` từ `stdout`/`stderr` của tiến trình con trước khi đưa vào `deque`.
3. **Lưu trữ Log & Báo cáo lỗi:**
   - Ghi toàn bộ raw log (100% không cắt gọt) của từng project ra thư mục `.build-logs/<project-name>.log`.
   - Khi tất cả hoàn tất: hiện lại con trỏ màn hình (`\033[?25h`), in bảng tổng kết thời gian build từng project. Nếu có project `FAILED`, tự động trích xuất và in ~15 dòng lỗi quan trọng cuối cùng ngay bên dưới bảng tổng kết kèm đường dẫn tới file `.log`, đồng thời trả về mã thoát `exit(1)`.
4. **Dọn dẹp tiến trình con an toàn (`Ctrl+C`):**
   - Khi người dùng nhấn `Ctrl+C` (`SIGINT`), phải diệt toàn bộ cây tiến trình con (bao gồm cả JVM daemon con do wrapper gọi ra): dùng `start_new_session=True` + `os.killpg` trên Linux/macOS, và `taskkill /F /T /PID` trên Windows, sau đó khôi phục trạng thái con trỏ terminal bình thường.

# Các tham số CLI cần hỗ trợ
- `--lines <int>`: Số dòng queue cho mỗi project (mặc định: 6, có thể chỉnh lên 10).
- `-j, --jobs <int>`: Số tiến trình build chạy song song tối đa (mặc định: 4).
- `--only <p1,p2>`: Chỉ build các project được chỉ định.
- `--skip-tests`: Tự động gắn `-x test` cho Gradle và `-DskipTests` cho Maven.
- `--clean`: Có chạy kèm goal/task `clean` hay không.

# Code mẫu tham chiếu (Core Architecture)
Hãy dùng kiến trúc `asyncio` + `deque` + ANSI rendering dưới đây làm nền tảng chuẩn và mở rộng thành sản phẩm hoàn chỉnh đáp ứng toàn bộ yêu cầu trên (chỉ dùng Python Standard Library, không phụ thuộc package bên ngoài để chạy được ngay ở mọi máy dev):

```python
import asyncio
import os
import re
import shutil
import signal
import subprocess
import sys
import time
from collections import deque
from pathlib import Path

if os.name == "nt":
    os.system("")
try:
    sys.stdout.reconfigure(encoding="utf-8")
except AttributeError:
    pass

ANSI_RE = re.compile(r"\x1b\[[0-9;?]*[a-zA-Z]")
SPINNER = ["⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏"]


class BuildTask:
    def __init__(self, name: str, cmd: str, cwd: Path, max_lines: int, log_dir: Path):
        self.name = name
        self.cmd = cmd
        self.cwd = cwd
        self.logs = deque(maxlen=max_lines)
        self.status = "QUEUED"  # QUEUED | RUNNING | SUCCESS | FAILED | CANCELLED
        self.start_time = None
        self.end_time = None
        self.proc = None
        self.log_file = log_dir / f"{name}.log"

    @property
    def elapsed(self) -> float:
        if self.start_time is None:
            return 0.0
        end = self.end_time if self.end_time is not None else time.time()
        return end - self.start_time


def kill_process_tree(proc: asyncio.subprocess.Process):
    if proc is None or proc.returncode is not None:
        return
    try:
        if os.name == "nt":
            subprocess.run(
                ["taskkill", "/F", "/T", "/PID", str(proc.pid)],
                stdout=subprocess.DEVNULL,
                stderr=subprocess.DEVNULL,
            )
        else:
            os.killpg(os.getpgid(proc.pid), signal.SIGTERM)
    except Exception:
        pass


async def execute_task(task: BuildTask, sem: asyncio.Semaphore):
    async with sem:
        task.status = "RUNNING"
        task.start_time = time.time()
        kwargs = {"start_new_session": True} if os.name != "nt" else {}

        try:
            task.proc = await asyncio.create_subprocess_shell(
                task.cmd,
                cwd=str(task.cwd),
                stdout=asyncio.subprocess.PIPE,
                stderr=asyncio.subprocess.STDOUT,
                limit=1024 * 1024,  # 1MB buffer chống lỗi dòng log quá dài
                **kwargs,
            )
            with open(task.log_file, "w", encoding="utf-8", errors="replace") as f:
                while True:
                    line = await task.proc.stdout.readline()
                    if not line:
                        break
                    text = line.decode("utf-8", errors="replace")
                    f.write(text)
                    f.flush()
                    clean = ANSI_RE.sub("", text).replace("\r", "").replace("\t", "    ").rstrip("\n")
                    if clean.strip():
                        task.logs.append(clean)

            rc = await task.proc.wait()
            task.status = "SUCCESS" if rc == 0 else f"FAILED (exit {rc})"
        except asyncio.CancelledError:
            kill_process_tree(task.proc)
            task.status = "CANCELLED"
            raise
        except Exception as exc:
            task.logs.append(f"Runner error: {exc}")
            task.status = "FAILED"
        finally:
            task.end_time = time.time()


def render_frame(tasks: list[BuildTask], prev_drawn: int, target_q_size: int, tick: int) -> int:
    term_size = shutil.get_terminal_size((100, 30))
    cols = max(50, term_size.columns - 2)
    max_rows = max(10, term_size.lines - 2)

    # Tự động tính số dòng queue sao cho tổng chiều cao không vượt quá màn hình terminal
    active_count = max(1, len(tasks))
    available_per_task = (max_rows - 2) // active_count - 1
    q_size = max(1, min(target_q_size, available_per_task))

    lines_out = []
    header = f"PARALLEL BUILDER  |  Total: {len(tasks)}  |  Queue: {q_size} lines/project"
    lines_out.append(f"\033[1m{header[:cols]}\033[0m")
    lines_out.append(f"\033[2m{'─' * min(cols, 80)}\033[0m")

    for t in tasks:
        if t.status == "RUNNING":
            badge, color = f"{SPINNER[tick % len(SPINNER)]} RUNNING", "\033[1;33m"
        elif t.status == "QUEUED":
            badge, color = "• QUEUED", "\033[2m"
        elif t.status == "SUCCESS":
            badge, color = "✓ SUCCESS", "\033[1;32m"
        else:
            badge, color = f"✗ {t.status}", "\033[1;31m"

        title = f"{badge}  {t.name} ({t.elapsed:.1f}s) -> {t.log_file}"
        lines_out.append(f"{color}{title[:cols]}\033[0m")

        visible_logs = list(t.logs)[-q_size:]
        for i in range(q_size):
            raw = visible_logs[i] if i < len(visible_logs) else ""
            if len(raw) > cols - 4:
                raw = raw[: cols - 7] + "..."
            lines_out.append(f"  │ {raw}")

    buf = []
    if prev_drawn > 0:
        buf.append(f"\033[{prev_drawn}A")
    buf.append("\033[?7l")  # Tắt tự động xuống dòng khi vẽ

    total_to_draw = max(len(lines_out), prev_drawn)
    for idx in range(total_to_draw):
        content = lines_out[idx] if idx < len(lines_out) else ""
        buf.append(f"\r{content}\033[0m\033[K\n")

    buf.append("\033[?7h")
    sys.stdout.write("".join(buf))
    sys.stdout.flush()
    return total_to_draw
```
